HOW IT WORKS:
─────────────

1. User clicks the yellow chat icon in bottom-right corner
2. Chat panel opens with animated slide-in
3. User asks a question about schemes
4. Backend receives message + user profile
5. System ranks eligible schemes (6-factor matching)
6. Gemini AI generates personalized response (or rule-based fallback)
7. Response displayed in chat panel
8. User can ask follow-up questions
9. Conversation history maintained during session

EXAMPLE CONVERSATION:
─────────────────────

User: "Which schemes am I eligible for?"

Bot: "Great! You're eligible for 10 schemes as an SC student in Maharashtra.
